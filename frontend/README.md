# AIReca Frontend

Интерфейс AI-администратора на Next.js.

## Технологии

- Next.js (Pages Router)
- React
- Tailwind CSS
- Hugeicons React
- CSS Modules

## Запуск

```bash
npm install
npm run dev
```

Дополнительные команды:

```bash
npm run lint
npm run build
npm start
```

Основная структура:

```text
components/  общие компоненты интерфейса
pages/       страницы и маршруты
styles/      глобальные стили и стили отдельных страниц
```
