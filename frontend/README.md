# AIReca Frontend

AI-администраторға арналған Next.js интерфейсі.

## Технологиялар

- Next.js (Pages Router)
- React
- Tailwind CSS
- Hugeicons
- CSS Modules

## Іске қосу

```bash
npm install
npm run dev
```

Қосымша командалар:

```bash
npm run lint
npm run build
npm start
```

Негізгі құрылым:

```text
components/  ортақ интерфейс компоненттері
pages/       беттер мен маршруттар
styles/      global және әр бетке арналған стильдер
```
